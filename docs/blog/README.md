# Материалы об агентной разработке

Эти материалы намечают блог о том, как автор работает с агентами и чем обоснованы его решения.

## Иерархия

Главная страница ведёт к темам.
Каждая тема объединяет связанные тезисы, объяснения, источники и ограничения.
[Перечень тезисов](theses.md) хранит выбранные направления, но ещё не раскрывает их как статьи.

| Тема | Состояние |
| --- | --- |
| Оркестрация и параллельная работа | Выбраны тезисы |
| Автономия и контроль | Выбраны тезисы |
| Безопасность и секреты | Выбраны тезисы |
| Проверки качества и мутации | Выбраны тезисы |
| Оценка агентов и навыков | Выбраны тезисы |
| Выбор модели и уровня рассуждения | Выбраны тезисы |
| Контекст и сжатие | [Пример страницы](context.md) |
| Документация, спецификации и комментарии | Выбраны тезисы |

Для начала каждая тема занимает одну страницу, но эту структуру можно изменить.
Markdown-файлы не являются работающим сайтом.

## Как читать материалы

Утверждение в перечне указывает направление для дальнейшего объяснения.
Оно не обязательно описывает доказанный результат или действующую практику автора.
Страница темы должна отличать позицию автора от исследований и личных измерений.
У каждого раскрытого тезиса нужны источник и пределы применимости.
Если подтверждение нельзя опубликовать или оно ещё не найдено, страница должна это указать.
