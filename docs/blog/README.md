## Как найти тезис

[Перечень тезисов](theses.md) ведёт по коду к объяснению, источнику и границам вывода.
Страницы отделяют позицию автора и данные о настройке от измерений и гипотез.
Если источника недостаточно для вывода о кодовых агентах, объяснение называет этот пробел.
