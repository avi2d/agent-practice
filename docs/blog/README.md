## Как пишется статья

Язык, словарь, порядок разделов и срок переписывания существующих статей собраны в [правилах для статей](reader-guide.md).
Я переписываю пробную статью [Оркестрация агентов](orchestration.md) по этим правилам.

## Как найти тезис

Если источника недостаточно для вывода о кодовых агентах, объяснение называет этот пробел.
