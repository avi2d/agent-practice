## Как пишется статья

Язык, словарь, порядок разделов и порядок переписывания существующих статей собраны в [правилах для статей](reader-guide.md).
По текущим правилам переписаны статьи [Автономия и контроль](autonomy.md), [Навыки и инструкции для агентов](skills.md) и [Checks](checks.md).
[Оркестрация агентов](orchestration.md) переписана по прежним правилам и ждёт правки по текущим.
Остальные статьи переписываются по одной.

## Как найти тезис

[Перечень тезисов](theses.md) ведёт к объяснению, источнику и границам вывода каждого тезиса.
Если источника недостаточно для вывода о кодовых агентах, объяснение называет этот пробел.
